# Frecent Jump

XeFMで最近訪問したディレクトリや、よく使うディレクトリへすばやく移動するための拡張機能です。訪問回数と最終訪問時刻から候補を並べ、一覧から選択して現在のペインで開きます。

[English README](README.md)

## 動作要件

- XeFM 1.10.0以降（拡張機能のmanifestで指定されている最小バージョン）
- デスクトップ版・ターミナル版のどちらでも利用できます

この拡張機能は外部プログラムや追加のPythonパッケージを必要としません。

## インストール

XeFMが使える環境で、次のコマンドを実行します。

```sh
xefm ext install github:SinisterSoftware/xefm-frecent-jump
```

インストール後、XeFMで **Tools ▸ Reload Configuration** を実行するか、XeFMを再起動してください。

## 使い方

拡張機能のアクション名は `frecent.jump` です。XeFMのコマンドパレットからアクションを選ぶか、既定のキー候補 `Alt-F` で実行します。キー候補は、他のアクションとの競合などによって自動で割り当てられないことがあります。

アクションを実行すると、訪問履歴にあるディレクトリがスコアの高い順に表示されます。目的のディレクトリを一覧から選ぶと、現在アクティブなペインがその場所へ移動します。現在開いているディレクトリは候補から除かれます。

XeFMでディレクトリを移動すると、その場所が訪問履歴に記録されます。訪問履歴がまだない場合は `frecent-jump: まだ履歴がありません` と表示されます。履歴に記録された場所が存在しなくなった後で選択すると、その項目は履歴から削除され、通知が表示されます。

### キー割り当ての変更

`Alt-F` が別のアクションに使われている場合や、別のキーを使いたい場合は、`~/.xefm/config.py` の `Config.KEY_BINDINGS` で割り当てを設定できます。たとえば `Ctrl-Shift-J` に割り当てるには、`Config` クラス内に次の設定を追加します。

```python
KEY_BINDINGS = {
    'frecent.jump': ['Ctrl-Shift-J'],
}
```

すでに `KEY_BINDINGS` がある場合は、新しい属性を重複して作らず、その辞書に `'frecent.jump': ['Ctrl-Shift-J']` を追加してください。`KEY_BINDINGS` に書かれていないキーはXeFMのキーマップ設定に従います。キーが反応しない場合は、他のアクションへの割り当てや、使用中のキーマップ・端末がそのキー入力に対応しているかを確認してください。設定変更後は **Tools ▸ Reload Configuration** を実行するか、XeFMを再起動します。

## 履歴の並び順

各ディレクトリのスコアは「訪問回数 × 最終訪問からの経過時間に応じた重み」で計算されます。最近の訪問ほど重みが大きくなります。

| 最終訪問からの経過時間 | 重み |
| --- | ---: |
| 1時間未満 | 4 |
| 1時間以上、24時間未満 | 2 |
| 24時間以上、7日未満 | 0.5 |
| 7日以上 | 0.25 |

そのため、最近使った場所は少ない訪問回数でも上位になりやすく、よく使う場所も繰り返しの訪問によって上位に表示されます。スコアが同じ場合の並び順は、この拡張機能では特別に定めていません。

## 履歴データとプライバシー

- 訪問履歴はユーザーのXeFM設定フォルダー内 `~/.xefm/state/frecency.json` にJSON形式で保存されます。Windowsでは通常 `%USERPROFILE%\.xefm\state\frecency.json` に相当します。
- 履歴にはディレクトリのパス、訪問回数、最終訪問時刻が含まれます。ファイルの内容を確認・削除する場合は、XeFMを終了してからこのファイルを操作してください。削除後は新しい履歴が作成されます。
- 履歴が2,000件を超えると、スコアの低い項目から200件が削除されます。
- URI形式などの仮想ディレクトリは履歴に記録されません。
- この拡張機能のコードは、履歴の記録や検索のために外部サービスへ接続しません。GitHubからのインストールや更新確認は、XeFMの拡張機能管理による別の処理です。
- 旧バージョンが `~/.xefm/extensions/frecency.json` に作成した履歴ファイルがあり、新しい保存先にファイルがない場合、拡張機能の初回利用時に新しい保存先へ移動します。

標準のXeFMの履歴やお気に入りとは別に管理されます。

## 制限とトラブルシューティング

- 初めて使うときや、記録された履歴がないときは候補がありません。まずXeFMでいくつかのディレクトリへ移動してから、もう一度実行してください。
- `frecent.jump` が見つからない場合は、拡張機能がインストールされていることを確認し、**Tools ▸ Reload Configuration** を実行するかXeFMを再起動してください。
- `Alt-F` で起動しない場合は、キーの競合や端末・OSによる入力の扱いが考えられます。上記の例のように別のキーを `KEY_BINDINGS` で割り当てるか、コマンドパレットからアクションを実行してください。
- 候補を選んでも移動できないディレクトリは、存在しない場所として履歴から除外されます。
- この拡張機能にユーザー設定項目はありません。動作を変えるための設定クラスや追加の依存パッケージもありません。
